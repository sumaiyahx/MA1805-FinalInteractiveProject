What inspired me for this project was my culture. Growing up as a South Asian female in the UK I used to feel overlooked in the media, especially in terms of fashion and jewellery. When South Asian style of jewellery was shown it was treated as something exotic rather than pieces with cultural meaning behind it. That is why I decided to base my project around my culture as it is something that's very meaningful to me and something that I am proud of.

For the sound effects on page 1, I used the website 'Free Sounds' and looked for the sound I felt fit the most. I initially wnated to use a click sound effect but couldn't find one I liked, so I ended up using a 'pop' sound effect instead. I feel as if the 'pop' effect gave more character to the page. I also planned on having South Asian music playing in the back but I didn't end up finding one suitable for the project. This is where I downloaded the 'pop' sound effect from https://freesound.org/people/mattskydoodle/sounds/259704/

While browsing on p5.js looking for inspiration, I came across this set of code and decided to implement it on the last page of my project. https://p5js.org/examples/imported-media-copy-image-data/ I thought it could be a fun, interactive 'guess the colour of the flag' activity, which is somewhat similar to 'guess the flag'. That is a game I personally enjoy playing. 

Sometimes I would refer to this https://learnxinyminutes.com/javascript/  which helped me to gain more understanding of JavaScript.

An issue I faced at the beginning of this project was when I had the let declarations at the very top of the page. When I had it there above the constants my code would not run properly so I swapped them around and that is when my code started working. However, I now feel way more confident with coding then I did at the start of the semester. I feel like I have the hang of it and now if my code isn't running properly I feel more confident in being able to identify the error afer carefully going through the code.
